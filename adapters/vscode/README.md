# oAX for VS Code

Local development preview for trusted, local TypeScript/JavaScript workspaces. Requires VS Code 1.105.0 or newer with a compatible Node runtime; 1.105.0 is the verified host. This is not a Marketplace release.

Install the locally built VSIX using **Extensions: Install from VSIX...**, then select code and run **oAX: Explain Selection** for a real Codex explanation. **Find Callers**, **Find Importers**, **Find Implementations**, and **Find Related Tests** return deterministic source evidence. Related tests use filename heuristics. Module resolution covers relative imports, bounded project aliases and exact workspace package exports. Full project configuration and external dependencies remain unsupported. Background indexing preserves the selected unsaved snapshot; **Show Index Status** reports refresh status and failures.

Explain previews context and asks before transmitting it. It requires Codex **0.159.2**, already signed in using the official client. Windows discovers the official desktop installation; alternatively set `oax.codexExecutable` in user settings to an absolute executable path. Usage may apply. Setup failures produce an actionable error; there is no automatic mock fallback. A hidden mock command exists only for deterministic acceptance tests. oAX disables provider environment/tool capabilities and inherited MCP servers in its private subprocess; provider execution does not perform refactors or run commands. Unsupported provider versions fail closed.

oAX displays activity in the status bar and a separate observed-symbol decoration. It does not move your selection. **oAX: Reconnect Runtime** releases connections and starts fresh sessions. Sessions are memory-only; repository indexing is refreshed on observations and commands. Only the selected editor buffer overlays disk; other unsaved editors are not included.

The runtime is bundled and uses authenticated private stdio, with no TCP listener. Exclusions and indexing budgets apply. Source excerpts can still contain secrets despite excluded credential paths; inspect the context before consenting. Local graph storage is experimental Node SQLite. Core explain and relationship commands do not modify source files.

**Refactor Selection with Codex Preview** proposes a replacement for saved selected code. Review the displayed context before sending it; truncated/redacted selections are rejected. Model output must contain only replacement and explanation strings. The runtime derives the single allowed path and range from the captured document, then shows a native diff. A separate approval authorizes that exact plan for 60 seconds; document and disk baselines are rechecked before writing. The proposal itself is unverified. Use **Run Selected Node Tests with Approval** for separately authorized verification. Multi-file model edits, file creation/deletion and arbitrary commands remain unsupported.

Uninstall through VS Code's extension manager. Rebuild and reinstall the VSIX to update this preview. Report operational failures with command/version information, never credentials or sensitive source. A supported release policy and private vulnerability channel remain prerequisites for publication.

**Rename Symbol with Preview** presents exact before/after text and paths, then requires approval and fresh saved-file baselines. Other dirty affected files must be saved first. Rename preserves semantic references in the supported module model, not arbitrary external consumers. Partial I/O failures are reported without claiming rollback.

**Run Selected Node Tests with Approval** authorizes one saved .test/.spec TypeScript or JavaScript file using the host Node executable. It discloses arguments, cwd and local-account execution rights, captures actual exit status, and supports timeout/cancellation. It does not execute package scripts. **Show Git History Evidence** reads local commits/blame for saved selected code. **Onboard Repository** presents graph evidence and explicitly labeled filename heuristics.

**Connect Read-Only GitHub Evidence** accepts a fine-grained token scoped to one selected repository with metadata, contents, pull-request, issue and check read access. The password input keeps it outside configuration and logs; retention defaults to this session, with optional VS Code secret storage. After approval, metadata is verified. **Show Associated GitHub PR Evidence** traces the first selected-line blame commit to bounded PR associations, reviews, comments, referenced issues and checks. Text references are heuristic and unavailable API results are explicit. It does not infer author intent or send evidence to a model. **Disconnect GitHub Evidence** releases memory state and offers removal of a remembered credential. Product authentication is separate from VS Code sign-in and chat connectors. Deterministic HTTP/permission acceptance passes; live authenticated product/UI acceptance is pending.

**Review Last Applied Edit and Test Evidence** shows the approved change identity and captured test results. Select a relevant saved test, then run **Run Selected Node Tests with Approval** to attach its evidence to the edited session. Changed source or tests invalidate the prior verification claim. The approval choices default to Cancel; complete details remain visible in oAX output. Refactoring offers a bug-fix objective or a custom description. Completed edits are not automatically rolled back.
