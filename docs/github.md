# Read-only GitHub evidence preview

The optional VS Code commands connect one explicitly selected `owner/repository`, verify metadata, then trace the first selected-line blame commit through bounded PR associations, reviews, timeline comments, referenced issues and check runs. These are fixed `https://api.github.com` GET routes, using REST API version **2026-03-10**. Titles/excerpts are bounded, conservatively redacted, treated as untrusted, and displayed with constructed GitHub references. Association does not establish author intent. See [historical evidence limits](history.md) and the [official commit/PR endpoint](https://docs.github.com/en/rest/commits/commits#list-pull-requests-associated-with-a-commit).

Run **oAX: Connect Read-Only GitHub Evidence**, enter the selected repository, then a fine-grained token scoped to that repository with metadata, contents, pull-request, issue and check read permissions. Use GitHub's [fine-grained token instructions](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens). Do not paste tokens into source, configuration, terminal arguments or this chat. The extension uses a password input and offers session-only credentials or optional [VS Code secret storage](https://code.visualstudio.com/api/references/vscode-api#SecretStorage). Token permissions may exceed the product's fixed GET-only operations; configure the least privilege needed.

After saving selected tracked code, run **Show Associated GitHub PR Evidence**. Reads require a verified connection and a scoped runtime grant for each exact repository route. Connection authorization lasts one hour. **Disconnect GitHub Evidence** releases the runtime credential and offers removal of a remembered token; reconnecting the runtime or closing VS Code also releases memory state. Expired connections fail closed and discard credentials when next used. Clearing JavaScript references is not secure memory erasure.

No GitHub writes, push, posting, repository source upload or model transmission are exposed. Credentials cross only the authenticated private parent/child transport and fixed-origin Authorization header, never graph/context/output/audit. Responses are capped at 64 KiB; timeout is eight seconds; redirects are rejected. HTTP authorization/rate-limit failures remain errors, not fabricated empty results.

Deterministic tests verify exact-grant denial, fixed origin/method/version, token non-disclosure including echoed credentials, response limits, untrusted text handling, session isolation, disconnect and distinct write denial. History-quality fixtures cover selected-line provenance and heuristic issue attribution. **Live authenticated product and credential-UI acceptance are not yet verified.** VS Code sign-in and this chat's connector authentication are separate. Pagination, GitHub App/team authentication and live-model historical narrative evaluation remain future work.
